BECOME HER — prima versione gratuita

Contenuto:
- index.html: app
- manifest.webmanifest: impostazioni installazione PWA
- sw.js: cache base per apertura offline dopo il primo caricamento

Istruzioni rapide:
1. Carica tutti e tre i file in un repository GitHub pubblico.
2. In Settings > Pages seleziona Deploy from a branch, branch main, folder /(root), Save.
3. Attendi la pubblicazione e apri l'indirizzo https://TUONOME.github.io/NOME-REPOSITORY/ con Safari su iPhone.
4. Safari > Condividi > Aggiungi alla schermata Home > attiva "Apri come app web" > Aggiungi.

I dati vengono salvati localmente nel browser/dispositivo. Esporta regolarmente un backup da Your space.
Questa versione è una base iniziale: le notifiche push richiedono un servizio server e non sono ancora configurate.
